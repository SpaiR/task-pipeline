# Documentation

Maintainer-facing docs for the task-pipeline plugin.

| File | Topic |
|------|-------|
| [contract.md](contract.md) | **The single source of truth** for the artifact protocol: the flat `.task/` layout and root resolution, the `.task/CLAUDE.md`, task, roadmap and spec formats, cross-artifact references, the producer/consumer table, the bash helpers, the reviewer agent, and the interaction conventions. |
| [usage.md](usage.md) | Pointer to the usage guides on the docs site. |
| [troubleshooting.md](troubleshooting.md) | Pointer to the troubleshooting guide on the docs site. |

Read `contract.md` before any non-trivial edit to a skill or a `skills/_lib/` helper. User-facing prose lives on the docs site, source under [`website/`](../website); the repo `README.md` is the GitHub landing page.
